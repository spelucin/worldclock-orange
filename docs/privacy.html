Privacy policy

Last updated: 30 September 2026

WorkClock Orange is a free, open-source Chrome extension. This policy explains what the extension does with your data. The short version: it stores nothing anywhere, because it has nowhere to store it.

Summary

  • No data is collected.
  • No data is sold or shared, because none is collected.
  • No analytics, advertising, or tracking of any kind.
  • No cookies.
  • No network requests at all.
  • Your settings stay on your device.

What the extension stores

When you save a city or change a preference, that value is written to your browser's local extension storage (chrome.storage.local). This storage belongs to your Chrome profile on your own device.

Data What it is Where it lives
Saved locations City label, IANA timezone identifier, country code, and the working hours you set for it chrome.storage.local, on your device
Preferences Theme mode, accent colour, interface language, and your own working hours chrome.storage.local, on your device

This data is never transmitted. Uninstalling the extension removes it. Clearing Chrome's extension storage also removes it.

Permissions, and why each one is needed

Permission Why it is required
storage Saves your cities and preferences on your device so they survive a browser restart.
alarms Schedules a periodic refresh so the toolbar badge and your cities stay accurate without you reopening the popup.

The extension requests no host permissions. It cannot read, change, or transmit the content of the web pages you visit, and it does not inject anything into them.

Network activity

The extension makes no network requests. It contacts no servers, no analytics endpoints, and no third-party services. It does not load remote code, so there is no code fetched at runtime. All city and timezone data is bundled inside the extension itself.

This site, which you are reading on, is a static page published on GitHub Pages. Like all websites, GitHub may process standard server logs such as IP addresses for security and abuse prevention. Those logs are handled by GitHub under GitHub's site policies, not by this extension.

Third parties

There are none. The extension bundles no third-party libraries, no fonts, and no remote scripts. It contains no advertising or affiliate links.

Children

The extension is not directed at children and collects no data from anyone.

Your rights

Because no data is collected, there is nothing for us to disclose, correct, or delete on request. You can remove everything the extension stores at any time by removing the extension, or by clearing its storage in chrome://extensions.

Changes to this policy

If a future version changes what the extension does with data, this policy will be updated here and the date above will change. The version's source code is public, so the behaviour described here can be checked against the code at any time.
